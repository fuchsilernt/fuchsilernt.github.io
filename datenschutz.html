Anwendung „Fuchsi lernt“

Die Anwendung „Fuchsi lernt“ nutzt die YouTube Data API ausschließlich, um vom Kanalbetreiber selbst erstellte Videos auf seinen eigenen YouTube-Kanal hochzuladen. Sie wird nur vom Kanalbetreiber verwendet. Es werden keine Daten anderer Personen abgefragt, gespeichert oder weitergegeben.

Der Zugriffsschlüssel für das Hochladen wird nur lokal beim Betreiber gespeichert und kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Die Nutzung der Google-APIs erfolgt gemäß der Google API Services User Data Policy. Für YouTube gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.
